# Release checklist

- [ ] Confirm tax rules against current official sources and effective dates.
- [ ] Obtain qualified review of calculation rules and edge cases.
- [ ] Add/update regression tests for relevant thresholds and boundaries.
- [ ] Run `npm test` successfully.
- [ ] Manually test both regimes, invalid/zero inputs, mobile layout and privacy page.
- [ ] Review page title, description, links and privacy disclosure.
- [ ] Review changes in a pull request before merging to `main`.
- [ ] Verify the production deployment after merge.
